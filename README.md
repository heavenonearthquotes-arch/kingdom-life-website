# Kingdom Life — Heaven on Earth

A responsive, static landing page for the free Kingdom Life Christian app.

## What’s included
- App icon and Heaven on Earth wordmark
- Responsive landing page for Bible reading, daily habits and devotionals
- Email sign-up calls to action linking to the existing Kingdom Life account flow
- No pricing, waitlist, payment form or placeholder registration form

## Run locally
Open `index.html` in a browser or serve this directory with any static file server.

The sign-up links point to the existing Kingdom Life app at:
`https://kingdomlifechristianplanner.lovable.app/auth?mode=signup`

## Hosting
This is a static site and can be hosted on GitHub Pages or another static hosting provider. No build step is required.
